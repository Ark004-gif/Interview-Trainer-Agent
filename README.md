## 🎯 What It Does

The **Interview Trainer Agent** prepares candidates for job interviews by:

| Feature | Description |
|---|---|
| 🎤 **Tailored Question Sets** | Role + experience-specific questions via IBM Granite + RAG |
| 📊 **Answer Evaluation** | AI scores your answer on 5 dimensions with improvement tips |
| 💡 **Model Answers** | Ideal answers retrieved from knowledge base + generated by Granite |
| 🗺️ **30-Day Prep Strategy** | Personalized roadmap based on your profile |
| 📄 **Resume Parsing** | Upload PDF/DOCX/TXT — skills auto-extracted |
| 📚 **Knowledge Base** | 50+ curated role-specific Q&As across 10 job roles |
| 🎭 **Behavioral Questions** | STAR framework guidance for soft skills |
| 📖 **HR Guide** | Dos, don'ts, salary negotiation, virtual interview tips |

## 🚀 Quick Start

### Prerequisites
- Python 3.11+
- IBM Cloud account (free Lite tier)
- IBM watsonx.ai service (free tier available)

### 1. Clone & Setup

**Windows:**
```bat
setup.bat
```

**Linux / macOS:**
```bash
bash setup.sh
```

### 2. Configure IBM Cloud Credentials

Open `.env` and fill in your credentials:

```env
IBM_WATSONX_API_KEY=your_api_key_here
IBM_WATSONX_PROJECT_ID=your_project_id_here
IBM_WATSONX_URL=https://us-south.ml.cloud.ibm.com
IBM_GRANITE_MODEL_ID=ibm/granite-13b-instruct-v2
```

**Where to get credentials:**
1. Go to [IBM Cloud](https://cloud.ibm.com) → Create account (free Lite tier)
2. Create a **watsonx.ai** service instance
3. Go to **Manage → API keys** → Create API key
4. Copy your **Project ID** from the watsonx.ai project settings

### 3. Start the Server

**Windows:**
```bat
start.bat
```

**Linux / macOS:**
```bash
bash start.sh
```

### 4. Open the App
- **UI:** http://localhost:8000
- **API Docs:** http://localhost:8000/api/docs

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/health` | System health check |
| `POST` | `/api/sessions` | Create interview session (JSON) |
| `POST` | `/api/sessions/upload` | Create session with resume file |
| `GET` | `/api/sessions/{id}` | Get session details |
| `POST` | `/api/questions/generate` | Generate tailored questions |
| `POST` | `/api/answers/evaluate` | Evaluate candidate answer |
| `POST` | `/api/answers/model` | Get model/ideal answer |
| `POST` | `/api/strategy` | Generate 30-day prep strategy |
| `GET` | `/api/roles` | List supported job roles |
| `GET` | `/api/experience-levels` | List experience levels |

Full interactive docs: **http://localhost:8000/api/docs**
